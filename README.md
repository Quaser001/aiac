# ABRISK: Antimicrobial Resistance Decision Intelligence

**ABRISK** is a structure-informed antibiotic risk stratification and decision intelligence platform. It is designed to support clinical professionals and researchers in the Indian subcontinent by providing mechanism-aware reasoning for antibiotic choices.

## Core Principles
1.  **No Hallucinations**: Uses only real, vetted data.
2.  **Explainability First**: Prioritizes biological reasoning over black-box predictions.
3.  **India-Centric**: Optimized for the specific resistance landscape of India.

## Project Structure
- `data/`: Raw and processed datasets (Git-ignored).
- `src/`: Source code.
    - `scout/`: Data discovery and validation scripts.
- `docs/`: Project documentation and design artifacts.
- `tests/`: Automated tests.
